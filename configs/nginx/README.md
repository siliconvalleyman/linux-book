# Nginx

`handbook.conf` — самостоятельный файл, включает статический сайт, два upstream-сервера, ограничение частоты, заголовки и структурированный журнал. TLS слушает только loopback. Корень сайта, журналы и сертификаты используют абсолютные пути под `/srv/handbook`. Разместите материалы с владельцем и правами учётной записи, запускающей Nginx, и обеспечьте доступ только на чтение к сайту. Сертификат с SAN для `lab.example` и ключ создайте в ВМ и храните ключ с режимом 0600.

Поднимите локальные обработчики на портах 18081 и 18082, затем выполните `nginx -t -c /абсолютный/путь/handbook.conf`. Запускайте из непривилегированной учётной записи. Проверьте статическую страницу и путь `/api/` через `curl --resolve lab.example:18443:127.0.0.1 --cacert путь_к_сертификату https://lab.example:18443/`. Для завершения используйте параметры `-c` с тем же файлом и `-s quit`.
