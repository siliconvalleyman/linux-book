# OpenSSH

В клиентском образце замените `host.example` и `operator`. Создайте отдельный ключ `ssh-keygen -t ed25519 -f ~/.ssh/handbook_ed25519`, защитите его парольной фразой. Проверьте отпечаток ключа сервера через консоль ВМ, затем установите свой публичный ключ в `authorized_keys` учётной записи. Проверьте клиент через `ssh -F client.conf -G handbook-lab`.

Серверный образец предполагает существующую группу `ssh-operators` и пользователя с работающим ключом. Проверьте членство и поддержку `Include` в штатном конфиге, затем используйте drop-in в `sshd_config.d`. Вычислите параметры через `sudo sshd -T -C user=operator,host=client.example,addr=192.0.2.10`, проверьте `sudo sshd -t` и только после этого перезагрузите конфигурацию службы. Сохраните первый сеанс и доступ к консоли до успешного подключения во втором. Для отката снимите drop-in, повторите проверку и reload.
