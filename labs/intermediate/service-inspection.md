# Файлы и свойства юнита

| Уровень | Время |
| --- | --- |
| Средний | 12 мин |

## Цель и подготовка

Сравните текст conf и состояние ssh.service либо systemd-journald.service.

Понадобится ВМ Ubuntu с systemd. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Один файл содержит текст юнита, второй — путь FragmentPath. Сначала проверьте вывод, затем запустите проверку ниже.
3. В контейнере без systemd используйте ВМ.

## Полное решение

```bash
systemctl cat systemd-journald.service > unit.txt
systemctl show -p FragmentPath systemd-journald.service > path.txt
```

## Проверка

```bash
test -s unit.txt && grep -E '^FragmentPath=/.+' path.txt
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
