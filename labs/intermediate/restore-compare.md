# Восстановление с хешем

| Уровень | Время |
| --- | --- |
| Средний | 15 мин |

## Цель и подготовка

Запишите хеш файла, восстановите из архива и проверьте внутри каталога назначения.

Понадобится GNU tar и sha256sum. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Вывод note: OK. Сначала проверьте вывод, затем запустите проверку ниже.
3. Манифест содержит относительный путь, запустите проверку из restore.

## Полное решение

```bash
mkdir source restore
printf 'important\n' > source/note; (cd source && sha256sum note) > manifest
tar -czf lab.tar.gz -C source .
tar -xzf lab.tar.gz -C restore
```

## Проверка

```bash
(cd restore && sha256sum -c ../manifest)
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
