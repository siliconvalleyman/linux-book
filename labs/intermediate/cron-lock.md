# Блокировка задачи cron

| Уровень | Время |
| --- | --- |
| Средний | 15 мин |

## Цель и подготовка

Захватите блокировку и проверьте код конкурирующего запуска.

Понадобится flock из util-linux. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Второй вызов вернул 75. Сначала проверьте вывод, затем запустите проверку ниже.
3. Внешняя команда должна удерживать блокировку до завершения внутренней.

## Полное решение

```bash
flock -x lab.lock bash -c 'rc=0; flock -n -E 75 lab.lock true || rc=$?; printf "%s\n" "$rc"' > result
```

## Проверка

```bash
grep -Fx 75 result
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
