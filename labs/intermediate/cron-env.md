# Окружение cron

| Уровень | Время |
| --- | --- |
| Средний | 15 мин |

## Цель и подготовка

Сымитируйте окружение с фиксированными PATH и HOME. Убедитесь, что интерактивные переменные отсутствуют.

Понадобится Bash и env. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Две строки, заданные при запуске. Сначала проверьте вывод, затем запустите проверку ниже.
3. В расписании используйте абсолютные пути.

## Полное решение

```bash
env -i HOME="$lab" PATH=/usr/bin:/bin /bin/bash -c 'printf "%s\n" "$HOME" "$PATH"' > cron.log
```

## Проверка

```bash
test "$(tail -n 1 cron.log)" = /usr/bin:/bin
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
