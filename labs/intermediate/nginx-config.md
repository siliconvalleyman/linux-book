# Проверка Nginx

| Уровень | Время |
| --- | --- |
| Средний | 15 мин |

## Цель и подготовка

Проверьте штатную конфигурацию и отследите список include без перезапуска.

Понадобится Одноразовая ВМ с nginx. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Проверка завершится с 0, конфиг содержит events. Сначала проверьте вывод, затем запустите проверку ниже.
3. Разрешите ошибки доступа до любого reload.

## Полное решение

```bash
sudo nginx -t
sudo nginx -T > nginx.txt
```

## Проверка

```bash
grep -E '^[[:space:]]*events[[:space:]]*\{' nginx.txt
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
