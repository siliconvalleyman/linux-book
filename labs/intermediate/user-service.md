# Одноразовая служба

| Уровень | Время |
| --- | --- |
| Средний | 15 мин |

## Цель и подготовка

Выполните пробную службу через пользовательский менеджер и передайте stdout клиенту.

Понадобится ВМ с пользовательским менеджером systemd. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Файл status содержит ready. Сначала проверьте вывод, затем запустите проверку ниже.
3. Для отсутствующей шины откройте полноценный локальный сеанс.

## Полное решение

```bash
systemd-run --user --wait --pipe --collect /usr/bin/printf '%s\n' ready > status
```

## Проверка

```bash
grep -Fx ready status
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
