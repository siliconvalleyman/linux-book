# Итоговый профиль SSH

| Уровень | Время |
| --- | --- |
| Средний | 12 мин |

## Цель и подготовка

Напишите отдельный клиентский профиль и проверьте его без соединения.

Понадобится OpenSSH client. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Записаны имя оператора, адрес и порт. Сначала проверьте вывод, затем запустите проверку ниже.
3. Проверьте имя псевдонима Host и параметр -F.

## Полное решение

```bash
printf '%s\n' 'Host lab' '    HostName 192.0.2.10' '    User operator' '    Port 2222' > ssh.conf
ssh -F ssh.conf -G lab > effective
```

## Проверка

```bash
grep -Fx 'port 2222' effective
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
