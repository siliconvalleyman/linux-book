# Проверка оглавления дампа

| Уровень | Время |
| --- | --- |
| Средний | 20 мин |

## Цель и подготовка

Создайте учебный dump custom и прочитайте TOC.

Понадобится Учебная база labdb и pg_dump, pg_restore. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. В заголовке оглавления указан формат CUSTOM. Сначала проверьте вывод, затем запустите проверку ниже.
3. Клиент pg_dump должен поддерживать версию сервера.

## Полное решение

```bash
pg_dump -Fc -f lab.dump labdb; pg_restore -l lab.dump > toc
```

## Проверка

```bash
grep -F 'Format: CUSTOM' toc
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
