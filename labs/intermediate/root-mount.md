# Корневая точка монтирования

| Уровень | Время |
| --- | --- |
| Средний | 10 мин |

## Цель и подготовка

Сравните источник монтирования и параметры файловой системы.

Понадобится findmnt и stat. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Показаны точка /, источник и тип ФС. Сначала проверьте вывод, затем запустите проверку ниже.
3. Строка типа в stat может использовать другое имя семейства.

## Полное решение

```bash
findmnt -T / -o TARGET,SOURCE,FSTYPE,OPTIONS
stat -f -c %T /
```

## Проверка

```bash
test "$(findmnt -T / -n -o TARGET)" = /
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
