# Порядок разрешения имён

| Уровень | Время |
| --- | --- |
| Средний | 12 мин |

## Цель и подготовка

Посмотрите источники hosts и разрешите localhost через NSS.

Понадобится glibc, getent. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. В типовой системе localhost разрешается в 127.0.0.1. Сначала проверьте вывод, затем запустите проверку ниже.
3. Если IPv4-записи нет, проверьте /etc/hosts и порядок NSS.

## Полное решение

```bash
grep '^hosts:' /etc/nsswitch.conf
getent ahostsv4 localhost
```

## Проверка

```bash
getent ahostsv4 localhost | grep -F 127.0.0.1
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
