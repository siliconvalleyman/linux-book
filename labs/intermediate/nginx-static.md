# Статическая страница Nginx

| Уровень | Время |
| --- | --- |
| Средний | 20 мин |

## Цель и подготовка

Поднимите отдельный Nginx с loopback, явными путями и временным pid.

Понадобится ВМ с Nginx и curl, свободный 18082. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Тело совпадает с index.html. Сначала проверьте вывод, затем запустите проверку ниже.
3. При 403 проверьте права на проход по пути и пользователя worker.

## Полное решение

```bash
mkdir www
printf 'nginx lab\n' > www/index.html
printf 'pid "%s/nginx.pid"; error_log stderr; events {} http { access_log off; server { listen 127.0.0.1:18082; root "%s/www"; } }\n' "$lab" "$lab" > nginx.conf
nginx -p "$lab/" -c "$lab/nginx.conf"
curl -fsS http://127.0.0.1:18082/ > actual
```

## Проверка

```bash
cmp www/index.html actual
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
nginx -p "$lab/" -c "$lab/nginx.conf" -s quit
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
