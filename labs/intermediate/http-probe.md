# Проверка локального HTTP

| Уровень | Время |
| --- | --- |
| Средний | 15 мин |

## Цель и подготовка

Запустите HTTP для своего каталога и проверьте статус и тело.

Понадобится Python 3 и curl, свободный 18080. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. В ответе ready. Сначала проверьте вывод, затем запустите проверку ниже.
3. Если порт занят, сопоставьте процесс и адрес через ss.

## Полное решение

```bash
printf 'ready\n' > index.html; python3 -m http.server 18080 --bind 127.0.0.1 > http.log 2>&1 & server=$!
curl --retry 3 --retry-connrefused -fsS http://127.0.0.1:18080/ > response
```

## Проверка

```bash
cmp index.html response
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
kill "$server" 2>/dev/null || true; wait "$server" 2>/dev/null || true
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
