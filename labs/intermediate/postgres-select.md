# Транзакция PostgreSQL

| Уровень | Время |
| --- | --- |
| Средний | 15 мин |

## Цель и подготовка

В транзакции создайте временную таблицу и вычислите сумму, затем откатите.

Понадобится Учебная база labdb и доступ psql. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Запрос выводит 5. Сначала проверьте вывод, затем запустите проверку ниже.
3. При отказе проверьте параметры PGHOST и текущую роль, не меняя серверную аутентификацию.

## Полное решение

```bash
psql -X -v ON_ERROR_STOP=1 -d labdb -At -c 'BEGIN; CREATE TEMP TABLE numbers (n int); INSERT INTO numbers VALUES (2),(3); SELECT sum(n) FROM numbers; ROLLBACK;' > pg.log
```

## Проверка

```bash
grep -Fx 5 pg.log
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
