# Проверка файла nftables

| Уровень | Время |
| --- | --- |
| Средний | 18 мин |

## Цель и подготовка

Напишите независимую таблицу с цепочкой без hook и проверьте её без загрузки.

Понадобится Одноразовая ВМ с nftables и sudo. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Проверка завершается с кодом 0. Сначала проверьте вывод, затем запустите проверку ниже.
3. Контейнер без CAP_NET_ADMIN не сможет проверить конфигурацию через ядро.

## Полное решение

```bash
printf '%s\n' 'table inet handbook_lab {' '  chain proposed {' '    tcp dport 2222 counter' '  }' '}' > sample.nft
sudo nft -c -f sample.nft
```

## Проверка

```bash
sudo nft -c -f sample.nft
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
