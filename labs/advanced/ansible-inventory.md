# Группы inventory

| Уровень | Время |
| --- | --- |
| Продвинутый | 12 мин |

## Цель и подготовка

Опишите один узел с local connection и прочитайте JSON inventory.

Понадобится ansible-core. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Под web показан localhost. Сначала проверьте вывод, затем запустите проверку ниже.
3. Проверьте порядок ключей и аргумент -i.

## Полное решение

```bash
printf '%s\n' '[web]' 'localhost ansible_connection=local' > inventory
ansible-inventory -i inventory --graph > graph
```

## Проверка

```bash
grep -F 'localhost' graph
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
