# Чтение метаданных RAID

| Уровень | Время |
| --- | --- |
| Продвинутый | 15 мин |

## Цель и подготовка

Сравните тип массива и число активных устройств из mdadm и mdstat.

Понадобится Одноразовая ВМ с активным учебным RAID 1 и mdadm. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. В mdstat отображается raid1. Сначала проверьте вывод, затем запустите проверку ниже.
3. Не меняйте массив. Если он отсутствует, используйте следующий опыт.

## Полное решение

```bash
cat /proc/mdstat > mdstat
cat mdstat
sudo mdadm --detail --scan
```

## Проверка

```bash
grep -F raid1 mdstat
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
