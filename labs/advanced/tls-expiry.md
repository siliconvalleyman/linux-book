# Порог окончания TLS

| Уровень | Время |
| --- | --- |
| Продвинутый | 12 мин |

## Цель и подготовка

Создайте сертификат на сутки и сравните проверки на один час и семь суток.

Понадобится OpenSSL. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Порог один час проходит, порог семь дней не проходит. Сначала проверьте вывод, затем запустите проверку ниже.
3. Проверьте часы ВМ и единицы -checkend.

## Полное решение

```bash
umask 077
openssl req -x509 -newkey rsa:2048 -nodes -days 1 -subj /CN=lab.example -keyout lab.key -out lab.crt
openssl x509 -in lab.crt -noout -checkend 3600
```

## Проверка

```bash
openssl x509 -in lab.crt -noout -checkend 3600 && ! openssl x509 -in lab.crt -noout -checkend 604800
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
