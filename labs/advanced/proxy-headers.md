# Заголовок обратного прокси

| Уровень | Время |
| --- | --- |
| Продвинутый | 20 мин |

## Цель и подготовка

Проксируйте запрос между локальными виртуальными серверами; выставьте X-Lab и верните его с upstream.

Понадобится ВМ с Nginx и curl, свободны 18083 и 18084. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Тело содержит verified. Сначала проверьте вывод, затем запустите проверку ниже.
3. Проверьте слушатели и добавленные заголовки.

## Полное решение

```bash
printf 'pid "%s/nginx.pid"; error_log stderr; events {} http { access_log off; server { listen 127.0.0.1:18084; return 200 "$http_x_lab"; } server { listen 127.0.0.1:18083; location / { proxy_set_header X-Lab verified; proxy_pass http://127.0.0.1:18084; } } }\n' "$lab" > nginx.conf
nginx -p "$lab/" -c "$lab/nginx.conf"
curl -fsS http://127.0.0.1:18083/ > actual
```

## Проверка

```bash
test "$(cat actual)" = verified
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
nginx -p "$lab/" -c "$lab/nginx.conf" -s quit
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
