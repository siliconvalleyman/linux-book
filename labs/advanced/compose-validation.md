# Проверка модели Compose

| Уровень | Время |
| --- | --- |
| Продвинутый | 12 мин |

## Цель и подготовка

Создайте описание сервиса и проверьте результирующее имя.

Понадобится Учебный Docker Compose v2. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. В списке один сервис worker. Сначала проверьте вывод, затем запустите проверку ниже.
3. Используйте пробелы и проверьте имя файла.

## Полное решение

```bash
printf '%s\n' 'services:' '  worker:' '    image: busybox:stable' '    command: ["true"]' > compose.yaml
docker compose config --services
```

## Проверка

```bash
test "$(docker compose config --services)" = worker
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
