# Проверка digest образа

| Уровень | Время |
| --- | --- |
| Продвинутый | 15 мин |

## Цель и подготовка

Загрузите busybox и найдите digest для последующей фиксации.

Понадобится Учебный Docker и доступ к Docker Hub. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. В digest присутствует @sha256:. Сначала проверьте вывод, затем запустите проверку ниже.
3. Локально собранный образ может не иметь RepoDigests.

## Полное решение

```bash
docker pull busybox:stable
docker image inspect --format '{{index .RepoDigests 0}}' busybox:stable > digest
```

## Проверка

```bash
grep -E '@sha256:[[:xdigit:]]{64}$' digest
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
