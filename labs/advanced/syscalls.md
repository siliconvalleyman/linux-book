# Подсчёт системных вызовов

| Уровень | Время |
| --- | --- |
| Продвинутый | 12 мин |

## Цель и подготовка

Включите агрегат по вызовам при чтении одного файла.

Понадобится ВМ со strace. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Есть хотя бы один вызов openat. Сначала проверьте вывод, затем запустите проверку ниже.
3. Отказ ptrace возможен при ограниченной политике контейнера.

## Полное решение

```bash
strace -c -o syscall.txt cat /etc/os-release >/dev/null
cat syscall.txt
```

## Проверка

```bash
grep -F openat syscall.txt
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
