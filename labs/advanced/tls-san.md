# Проверка SAN учебного TLS

| Уровень | Время |
| --- | --- |
| Продвинутый | 15 мин |

## Цель и подготовка

Создайте краткоживущий самоподписанный сертификат с SAN и проверьте имя.

Понадобится OpenSSL с параметром -addext. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Вывод содержит DNS:lab.example. Сначала проверьте вывод, затем запустите проверку ниже.
3. CN не заменяет корректный SAN для современных клиентов.

## Полное решение

```bash
umask 077
openssl req -x509 -newkey rsa:2048 -nodes -days 1 -subj /CN=lab.example -addext 'subjectAltName=DNS:lab.example' -keyout lab.key -out lab.crt
openssl x509 -in lab.crt -noout -ext subjectAltName
```

## Проверка

```bash
openssl verify -CAfile lab.crt -verify_hostname lab.example lab.crt
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
