# Метрики HTTP из журнала

| Уровень | Время |
| --- | --- |
| Продвинутый | 12 мин |

## Цель и подготовка

Преобразуйте учебный набор кодов статуса в число 5xx и долю ошибок.

Понадобится GNU awk. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Доля 0.50. Сначала проверьте вывод, затем запустите проверку ниже.
3. При пустом входе защитите деление проверкой NR.

## Полное решение

```bash
printf '200\n503\n200\n502\n' > statuses
awk '$1>=500 && $1<600 {err++} END {printf "%.2f\n", err/NR}' statuses > rate
```

## Проверка

```bash
grep -Fx 0.50 rate
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
