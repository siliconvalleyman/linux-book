# Создание и снятие тестового LVM

| Уровень | Время |
| --- | --- |
| Продвинутый | 25 мин |

## Цель и подготовка

Создайте VG и LV на loop-устройстве, выделенном только для вашего файла.

Понадобится Одноразовая ВМ, sudo, lvm2, util-linux. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. lvs показывает LV test размером около 16 MiB. Сначала проверьте вывод, затем запустите проверку ниже.
3. При ошибке фильтра lvm2 разрешите только созданное loop-устройство в настройках тестовой ВМ.

## Полное решение

```bash
truncate -s 128M disk.img
dev=$(sudo losetup --find --show "$lab/disk.img")
vg="hblab$BASHPID"
sudo pvcreate "$dev"
sudo vgcreate "$vg" "$dev"
sudo lvcreate -L 16M -n test "$vg"
```

## Проверка

```bash
sudo lvs "$vg/test"
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
sudo lvremove -y "$vg/test"; sudo vgremove -y "$vg"; sudo pvremove "$dev"; sudo losetup -d "$dev"
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
