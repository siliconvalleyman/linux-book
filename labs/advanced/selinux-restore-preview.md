# Предварительное восстановление метки

| Уровень | Время |
| --- | --- |
| Продвинутый | 15 мин |

## Цель и подготовка

Сравните метку учебного файла с политикой в домашнем каталоге.

Понадобится Одноразовая Fedora с SELinux, policycoreutils. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. При нормальной метке restorecon может ничего не вывести. Сначала проверьте вывод, затем запустите проверку ниже.
3. Проверьте, что домашний каталог находится на ФС с метками.

## Полное решение

```bash
probe=$(mktemp "$HOME/handbook-label.XXXXXXXX")
ls -Z "$probe"
restorecon -nv "$probe"
```

## Проверка

```bash
matchpathcon -V "$probe"
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
rm -- "$probe"
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
