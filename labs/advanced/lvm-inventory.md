# Инвентаризация LVM

| Уровень | Время |
| --- | --- |
| Продвинутый | 15 мин |

## Цель и подготовка

Сопоставьте физические и логические тома по имени группы.

Понадобится Одноразовая ВМ, установлен lvm2 и есть учебная VG. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Имя учебной VG видно в обоих выводах. Сначала проверьте вывод, затем запустите проверку ниже.
3. Для лабы возьмите ВМ с LVM и хотя бы одним логическим томом.

## Полное решение

```bash
sudo pvs -o pv_name,vg_name
sudo lvs -o lv_name,vg_name,lv_size
```

## Проверка

```bash
sudo vgs --noheadings -o vg_name | grep -E '[^[:space:]]'
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
