# Ограничения systemd-службы

| Уровень | Время |
| --- | --- |
| Продвинутый | 15 мин |

## Цель и подготовка

Сравните свойства из менеджера systemd и оценку песочницы службы.

Понадобится ВМ с systemd. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Вывод перечисляет включённые и отсутствующие ограничения. Сначала проверьте вывод, затем запустите проверку ниже.
3. Оценка зависит от версии systemd и конфигурации.

## Полное решение

```bash
systemctl show -p NoNewPrivileges -p PrivateTmp systemd-journald.service > props
systemd-analyze security systemd-journald.service > score
```

## Проверка

```bash
grep '^NoNewPrivileges=' props && test -s score
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
