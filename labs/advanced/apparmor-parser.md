# Разбор профиля AppArmor

| Уровень | Время |
| --- | --- |
| Продвинутый | 20 мин |

## Цель и подготовка

Разберите профиль учебного имени, пропуская загрузку в ядро и чтение кэша.

Понадобится ВМ Ubuntu с apparmor_parser. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Разбор проходит с кодом 0. Сначала проверьте вывод, затем запустите проверку ниже.
3. Не используйте -r: оно заменяет загруженный профиль.

## Полное решение

```bash
printf '%s\n' 'profile handbook-lab {' '  /usr/bin/true ix,' '}' > lab.profile; apparmor_parser -Q -T lab.profile
```

## Проверка

```bash
apparmor_parser -Q -T lab.profile
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
