# Политика входа OpenSSH

| Уровень | Время |
| --- | --- |
| Продвинутый | 15 мин |

## Цель и подготовка

Проверьте эффективную политику для локального контекста, сравните пароль и ключ.

Понадобится ВМ с openssh-server и sudo. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Видны правила permitrootlogin и passwordauthentication. Сначала проверьте вывод, затем запустите проверку ниже.
3. Match зависит от полного контекста, не применяйте правки из текущего SSH-сеанса.

## Полное решение

```bash
sudo sshd -T -C user=operator,host=localhost,addr=127.0.0.1 > effective
```

## Проверка

```bash
grep '^permitrootlogin ' effective && grep '^passwordauthentication ' effective
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
