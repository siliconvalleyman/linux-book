# Моделирование RPO

| Уровень | Время |
| --- | --- |
| Продвинутый | 15 мин |

## Цель и подготовка

Посчитайте интервал между доступной копией и инцидентом и сопоставьте с целевыми 30 минутами.

Понадобится GNU date. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Интервал 45 минут превышает целевые 30. Сначала проверьте вывод, затем запустите проверку ниже.
3. Приводите времена событий к одной временной шкале.

## Полное решение

```bash
copy=$(date -u -d '2025-01-01 09:15 UTC' +%s)
incident=$(date -u -d '2025-01-01 10:00 UTC' +%s)
loss=$(( (incident-copy)/60 ))
printf '%s\n' "$loss"
```

## Проверка

```bash
test "$loss" -eq 45 && test "$loss" -gt 30
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
