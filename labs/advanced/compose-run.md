# Задание Compose

| Уровень | Время |
| --- | --- |
| Продвинутый | 15 мин |

## Цель и подготовка

Запустите одноразовую задачу в отдельном проекте и заберите её код.

Понадобится Учебный Docker Compose v2 с busybox:stable. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Файл содержит finished. Сначала проверьте вывод, затем запустите проверку ниже.
3. Если daemon недоступен, проверьте контекст и права.

## Полное решение

```bash
printf '%s\n' 'services:' '  worker:' '    image: busybox:stable' '    command: ["echo", "finished"]' > compose.yaml
project="handbook$BASHPID"
docker compose -p "$project" run --rm -T worker > run.log
```

## Проверка

```bash
grep -Fx finished run.log
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
docker compose -p "$project" down
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
