# Практические лаборатории

Для работы с файлами используйте временный каталог на Linux. Для сети, управления учётными записями, монтирования, контейнеров и кластеров подготовьте одноразовую ВМ и снимок. В каждой работе приведены ожидаемые признаки результата. Набор упражнений требует разного программного обеспечения, указанного в разделе подготовки.
