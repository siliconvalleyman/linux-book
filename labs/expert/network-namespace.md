# Отдельный сетевой стек

| Уровень | Время |
| --- | --- |
| Экспертный | 20 мин |

## Цель и подготовка

Посмотрите интерфейсы внутри нового сетевого пространства и поднимите его loopback.

Понадобится Одноразовая ВМ, sudo и iproute2. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Внутри виден только lo. Сначала проверьте вывод, затем запустите проверку ниже.
3. Permission denied требует полномочий ВМ, не ослабляйте политики хоста.

## Полное решение

```bash
sudo unshare --net sh -c 'ip link set lo up; ip -br link' > links
```

## Проверка

```bash
test "$(wc -l < links)" -eq 1 && grep '^lo ' links
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
