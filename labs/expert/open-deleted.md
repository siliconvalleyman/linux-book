# Удалённый файл с открытым дескриптором

| Уровень | Время |
| --- | --- |
| Экспертный | 15 мин |

## Цель и подготовка

Откройте учебный файл, удалите имя и докажите, что данные доступны через открытый дескриптор.

Понадобится Bash и readlink. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Цель помечена (deleted), путь note отсутствует. Сначала проверьте вывод, затем запустите проверку ниже.
3. Не перезапускайте оболочку: дескриптор принадлежит ей.

## Полное решение

```bash
printf 'held\n' > note
exec 7<note
rm -- note
readlink "/proc/$$/fd/7"
```

## Проверка

```bash
test ! -e note && grep -Fx held <&7
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
exec 7<&-
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
