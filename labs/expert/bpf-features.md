# Непривилегированная проба eBPF

| Уровень | Время |
| --- | --- |
| Экспертный | 20 мин |

## Цель и подготовка

Соберите сведения о возможностях загрузки без административных прав.

Понадобится ВМ с bpftool. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Отчёт различает настройки ядра и доступность типов программ. Сначала проверьте вывод, затем запустите проверку ниже.
3. Негативный результат может быть следствием ограничений видимости.

## Полное решение

```bash
LC_ALL=C bpftool feature probe unprivileged > features
```

## Проверка

```bash
grep -i bpf features
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
