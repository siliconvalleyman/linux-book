# Независимое монтирование

| Уровень | Время |
| --- | --- |
| Экспертный | 25 мин |

## Цель и подготовка

Смонтируйте временную ФС в отдельном namespace и сравните видимость с родителем.

Понадобится Одноразовая ВМ, sudo, unshare. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Дочерний вывод содержит tmpfs, снаружи точка не смонтирована. Сначала проверьте вывод, затем запустите проверку ниже.
3. Private propagation обязательна для удержания монтирования внутри опыта.

## Полное решение

```bash
mkdir point
sudo unshare --mount --propagation private sh -c 'mount -t tmpfs -o size=4m tmpfs "$1"; findmnt -n -o FSTYPE --mountpoint "$1"' sh "$lab/point" > child
```

## Проверка

```bash
grep -Fx tmpfs child && ! mountpoint -q point
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
