# Проверка типа ядра через BTF

| Уровень | Время |
| --- | --- |
| Экспертный | 20 мин |

## Цель и подготовка

Прочитайте BTF загруженного ядра и проверьте описание task_struct.

Понадобится ВМ с CONFIG_DEBUG_INFO_BTF, bpftool. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Есть запись STRUCT 'task_struct'. Сначала проверьте вывод, затем запустите проверку ниже.
3. Отсутствие BTF требует другой сборки ядра или соответствующего артефакта дистрибутива.

## Полное решение

```bash
bpftool btf dump file /sys/kernel/btf/vmlinux format raw > types
```

## Проверка

```bash
grep -F "STRUCT 'task_struct'" types
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
