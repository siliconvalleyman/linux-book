# Сравнение окон PSI

| Уровень | Время |
| --- | --- |
| Экспертный | 15 мин |

## Цель и подготовка

Сохраните два образца PSI и сравните накопленный счётчик some.

Понадобится ВМ с PSI. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Счётчик второго образца не меньше первого. Сначала проверьте вывод, затем запустите проверку ниже.
3. Убедитесь, что файлы не пусты и система не перезагружалась.

## Полное решение

```bash
awk '/^some/{split($5,a,"="); print a[2]}' /proc/pressure/cpu > first
sleep 2
awk '/^some/{split($5,a,"="); print a[2]}' /proc/pressure/cpu > second
```

## Проверка

```bash
test "$(cat second)" -ge "$(cat first)"
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
