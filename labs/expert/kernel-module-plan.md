# Модуль и зависимости

| Уровень | Время |
| --- | --- |
| Экспертный | 15 мин |

## Цель и подготовка

Постройте план загрузки overlay для тестового ядра без записи.

Понадобится ВМ с overlay и kmod. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. План показывает путь insmod либо builtin. Сначала проверьте вывод, затем запустите проверку ниже.
3. Для встроенного модуля отдельного .ko может не быть.

## Полное решение

```bash
modinfo overlay > info
modprobe --show-depends overlay > plan
```

## Проверка

```bash
test -s info && grep -E '^(insmod|builtin) ' plan
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
