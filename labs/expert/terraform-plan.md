# План встроенного ресурса

| Уровень | Время |
| --- | --- |
| Экспертный | 20 мин |

## Цель и подготовка

Создайте план для terraform_data без облачных учётных данных и найдите действие create.

Понадобится Terraform 1.4 или новее. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. План добавляет один ресурс. Команда apply не нужна. Сначала проверьте вывод, затем запустите проверку ниже.
3. Если есть старый state, используйте свежий каталог.

## Полное решение

```bash
printf '%s\n' 'resource "terraform_data" "lab" {' '  input = "sample"' '}' > main.tf
terraform init -input=false
terraform plan -out=lab.plan
```

## Проверка

```bash
terraform show -no-color lab.plan | grep -F '1 to add, 0 to change, 0 to destroy'
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
