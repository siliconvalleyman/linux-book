# Контроль изменений учебных доказательств

| Уровень | Время |
| --- | --- |
| Экспертный | 15 мин |

## Цель и подготовка

Зафиксируйте хеш копии и проверьте целостность до и после имитации изменения.

Понадобится GNU sha256sum. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. Изначально OK, после дописывания FAILED. Сначала проверьте вывод, затем запустите проверку ниже.
3. Работайте с копией. Сохраняйте хеш отдельно от изменяемого носителя.

## Полное решение

```bash
printf 'sample event\n' > export.log; sha256sum export.log > SHA256SUMS; sha256sum -c SHA256SUMS
printf 'another event\n' >> export.log
```

## Проверка

```bash
! sha256sum -c SHA256SUMS
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
