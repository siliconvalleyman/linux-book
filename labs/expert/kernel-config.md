# Конфигурация загруженного ядра

| Уровень | Время |
| --- | --- |
| Экспертный | 15 мин |

## Цель и подготовка

Проверьте флаги cgroups и BPF в конфигурации ядра.

Понадобится ВМ Debian с `/boot/config-<release>`. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. В типовом ядре оба параметра включены. Сначала проверьте вывод, затем запустите проверку ниже.
3. Если конфигурация предоставляется через /proc/config.gz, используйте zgrep.

## Полное решение

```bash
config="/boot/config-$(uname -r)"
grep -E '^CONFIG_(CGROUPS|BPF)=' "$config"
```

## Проверка

```bash
grep -Fx CONFIG_CGROUPS=y "$config" && grep -Fx CONFIG_BPF=y "$config"
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
