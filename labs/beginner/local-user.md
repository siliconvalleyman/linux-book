# Учётная запись в ВМ

| Уровень | Время |
| --- | --- |
| Начальный | 15 мин |

## Цель и подготовка

Создайте тестовую группу и пользователя без домашнего каталога.

Понадобится Одноразовая ВМ Debian либо Ubuntu, sudo. Выполняйте команды только в одноразовой учебной ВМ. Перед изменениями кластера или Docker подтвердите, что работаете с локальным стендом.

Откройте Bash и подготовьте рабочий каталог.

```bash
previous_directory=$PWD
lab=$(mktemp -d "${TMPDIR:-/tmp}/handbook.XXXXXXXX")
cd -- "$lab"
```

## Ход работы

1. Выполните описанное действие в подготовленном каталоге. Используйте команды из решения, если нужно сверить последовательность.
2. У учётной записи задана группа handbook-lab. Сначала проверьте вывод, затем запустите проверку ниже.
3. Если имя занято, создайте новый снимок либо выберите новое имя.

## Полное решение

```bash
sudo groupadd handbook-lab
sudo useradd -M -g handbook-lab -s /usr/sbin/nologin handbook-lab
```

## Проверка

```bash
test "$(id -gn handbook-lab)" = handbook-lab
```

Ожидается код 0. Если команда печатает результат, сопоставьте его с ожидаемым состоянием из задания.

## Очистка

Завершите созданные ресурсы и удалите файлы временного каталога. Для упражнений, меняющих состояние системы или кластера, при частичном сбое верните снимок ВМ.

```bash
sudo userdel handbook-lab; sudo groupdel handbook-lab
cd -- "$previous_directory" &&
    [[ ${lab:-} == "${TMPDIR:-/tmp}"/handbook.???????? && -d $lab && ! -L $lab ]] &&
    find "$lab" -xdev -depth -mindepth 1 -delete &&
    rmdir -- "$lab"
```
