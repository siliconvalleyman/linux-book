# SSH

`ssh -G` показывает эффективные параметры клиента. `sshd -t` проверяет сервер, `sshd -T` показывает итоговые настройки. Сверьте ключ хоста по доверенному каналу перед первым подключением и оставьте действующий сеанс при изменении сервера.
