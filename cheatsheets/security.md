# Безопасность

`nft list ruleset` отражает активные правила. `nft -c -f lab.nft` проверяет файл без применения. `ausearch -m AVC -ts today` помогает сопоставить отказ с политикой SELinux. Подпись файла проверяйте ключом, отпечаток которого подтверждён отдельно.
