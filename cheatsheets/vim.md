# Редактор Vim

`Esc` возвращает в нормальный режим, `i` открывает ввод, `:w` сохраняет, `:q` завершает. `/pattern` ищет вперёд, `n` повторяет поиск. `u` отменяет последнее изменение, `Ctrl-r` повторяет отменённое. `:set number` показывает номера, `:set list` визуализирует пробельные символы.
