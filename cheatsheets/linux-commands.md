# Справочник команд Linux

Примеры ориентированы на Bash и GNU/Linux. Утилиты могут требовать отдельного пакета. Подготовьте указанные учебные файлы и используйте только свой стенд. Команды изменения состояния запускайте в одноразовой ВМ. Синтаксис и доступность параметров сверяйте с `man` установленной версии.

## Система

| Назначение | Синтаксис на примере | Параметры и замечания |
| --- | --- | --- |
| Имя и релиз ядра | `uname -sr` | -s имя, -r релиз |
| Состояние имени хоста и ОС | `hostnamectl status` | status показывает свойства без изменений |
| Время работы в читаемом виде | `uptime -p` | -p скрывает технические поля |
| Метка времени UTC | `date -u +%FT%TZ` | -u выбирает UTC, %F и %T форматируют дату и время |
| Признак синхронизации времени | `timedatectl show -p NTPSynchronized` | -p ограничивает вывод указанным свойством |
| Системная локаль и раскладка | `localectl status` | status читает настройки |
| Топология процессоров | `lscpu -e=CPU,CORE,SOCKET` | -e задаёт колонки |
| Число установленных логических CPU | `nproc --all` | --all включает недоступные текущему процессу CPU |
| Дерево USB | `lsusb -t` | -t отображает иерархию |
| Устройства PCI с идентификаторами | `lspci -nn` | -nn показывает имена и числа |
| Данные прошивки из SMBIOS | `dmidecode -t bios` | -t ограничивает тип; может требовать root |
| Сеансы logind | `loginctl list-sessions` | list-sessions перечисляет активные записи |
| Архитектура машины | `arch` | без параметров выводит архитектуру ядра |
| Разрядность long в текущей среде | `getconf LONG_BIT` | LONG_BIT — имя параметра |
| Признак виртуальной машины | `systemd-detect-virt --vm` | --vm ограничивает поиск типами ВМ |
