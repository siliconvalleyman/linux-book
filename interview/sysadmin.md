# Системное администрирование

## Вопросы и ответы

### Как определить, что произошло во время предыдущей загрузки?

Сначала journalctl --list-boots определяет доступные загрузки, затем journalctl -b -1 показывает прошлую. Если истории нет, проверьте постоянное хранилище и политику ротации.

### Как проверить, что symlink изменяется атомарно?

Создайте новую ссылку под отдельным именем в том же каталоге и выполните rename поверх старой. У наблюдателя будет старый либо новый путь. Для устойчивости при падении учитывайте гарантии ФС и синхронизацию каталога.

### Когда использовать отдельного системного пользователя?

Разные приложения получают разные UID для ограничения доступа к файлам и процессам. Для сервиса без интерактивного входа указывайте закрытую оболочку и минимальные группы. В systemd динамический UID подходит при подконтрольном хранении состояния.

### Зачем разделять /var и корневой том?

Разделение помогает ограничить влияние роста журналов и изменяемых данных. Оно добавляет отдельный бюджет места и новые зависимости загрузки. Размер выбирают по профилю данных и контролируют inode и блоки.

### Как выбрать рестарт systemd для краткоживущей задачи?

Для oneshot обычно нужен явный статус и политика повторов в управляющем процессе или таймере. Для демона Restart=on-failure и ограничения частоты не дают бесконечно перегружать систему. Учитывайте StartLimitBurst.

### Как проверить часы без подмены времени?

Сравните timedatectl, данные chronyc tracking или клиента NTP и внешние источники наблюдения. Проверьте разницу UTC и смещение часов. Для журналов храните одновременно время события и время приёма.

### Чем rsync -a отличается от полноценной политики резервирования?

Он копирует дерево с основными метаданными. Версии, отдельные носители, шифрование и защита от удаления требуют дополнительных механизмов. ACL и xattrs также требуют соответствующих опций и поддержки назначения.

### Нужно ли выполнять fsck на смонтированном томе?

Для меняющих метаданные режимов сначала обеспечьте размонтирование или работайте с согласованной копией. Правила зависят от файловой системы. Проверяйте явное устройство и возможность восстановления.

### Как подтвердить, что ресурс занят после mount?

Найдите держателей через fuser или lsof, проверьте вложенные монтирования и текущие каталоги процессов. Завершайте только согласованные процессы. Lazy unmount откладывает освобождение и может скрывать живые ссылки.

### Что произойдёт при недостатке места в каталоге tmpfs?

Запись может вернуть ENOSPC при достижении лимита размера или inode. Увеличение tmpfs влияет на доступную память и swap. Сначала оцените нужный размер и обнаружьте источник роста.

### Как обновить пакет с минимальным простоем?

Проверьте симуляцию, release notes и сохранность данных, затем обновляйте экземпляры по одному. Контролируйте health checks и зависимые клиенты. План отката должен учитывать совместимость схем и форматов.

### Почему run directory следует создавать при каждом запуске?

/run обычно временный и очищается при загрузке. RuntimeDirectory в systemd создаёт каталог с владельцем службы и управляет временем жизни. Для постоянных данных используйте StateDirectory либо выделенное хранилище.

## Практические сценарии

### Как решить задачу «Порядок разрешения имён» на стенде?

Посмотрите источники hosts и разрешите localhost через NSS. В типовой системе localhost разрешается в 127.0.0.1. Если IPv4-записи нет, проверьте /etc/hosts и порядок NSS.

Критерий приёмки проверяется в подготовленном стенде.

```bash
getent ahostsv4 localhost | grep -F 127.0.0.1
```

[Условия, команды и разбор задачи](../labs/intermediate/local-resolution.md)

### Как решить задачу «Одноразовая служба» на стенде?

Выполните пробную службу через пользовательский менеджер и передайте stdout клиенту. Файл status содержит ready. Для отсутствующей шины откройте полноценный локальный сеанс.

Критерий приёмки проверяется в подготовленном стенде.

```bash
grep -Fx ready status
```

[Условия, команды и разбор задачи](../labs/intermediate/user-service.md)

### Как решить задачу «Файлы и свойства юнита» на стенде?

Сравните текст conf и состояние ssh.service либо systemd-journald.service. Один файл содержит текст юнита, второй — путь FragmentPath. В контейнере без systemd используйте ВМ.

Критерий приёмки проверяется в подготовленном стенде.

```bash
test -s unit.txt && grep -E '^FragmentPath=/.+' path.txt
```

[Условия, команды и разбор задачи](../labs/intermediate/service-inspection.md)

### Как решить задачу «Календарь таймера» на стенде?

Проверьте правило запуска в понедельник утром и посмотрите три срабатывания. Показаны нормализованное правило и следующие срабатывания. Учитывайте временную зону при сравнении дат.

Критерий приёмки проверяется в подготовленном стенде.

```bash
grep -F 'Next elapse:' schedule
```

[Условия, команды и разбор задачи](../labs/intermediate/timer-calendar.md)

### Как решить задачу «Окружение cron» на стенде?

Сымитируйте окружение с фиксированными PATH и HOME. Убедитесь, что интерактивные переменные отсутствуют. Две строки, заданные при запуске. В расписании используйте абсолютные пути.

Критерий приёмки проверяется в подготовленном стенде.

```bash
test "$(tail -n 1 cron.log)" = /usr/bin:/bin
```

[Условия, команды и разбор задачи](../labs/intermediate/cron-env.md)

### Как решить задачу «Блокировка задачи cron» на стенде?

Захватите блокировку и проверьте код конкурирующего запуска. Второй вызов вернул 75. Внешняя команда должна удерживать блокировку до завершения внутренней.

Критерий приёмки проверяется в подготовленном стенде.

```bash
grep -Fx 75 result
```

[Условия, команды и разбор задачи](../labs/intermediate/cron-lock.md)

### Как решить задачу «Файловая система в образе» на стенде?

Создайте маленький образ, отформатируйте только этот файл и прочитайте сигнатуру. Тип ext4 и UUID видны в выводе. Убедитесь, что disk.img обычный файл внутри временного каталога.

Критерий приёмки проверяется в подготовленном стенде.

```bash
test "$(blkid -p -s TYPE -o value disk.img)" = ext4
```

[Условия, команды и разбор задачи](../labs/intermediate/loop-ext4.md)

### Как решить задачу «Корневая точка монтирования» на стенде?

Сравните источник монтирования и параметры файловой системы. Показаны точка /, источник и тип ФС. Строка типа в stat может использовать другое имя семейства.

Критерий приёмки проверяется в подготовленном стенде.

```bash
test "$(findmnt -T / -n -o TARGET)" = /
```

[Условия, команды и разбор задачи](../labs/intermediate/root-mount.md)

### Как решить задачу «Проверка Nginx» на стенде?

Проверьте штатную конфигурацию и отследите список include без перезапуска. Проверка завершится с 0, конфиг содержит events. Разрешите ошибки доступа до любого reload.

Критерий приёмки проверяется в подготовленном стенде.

```bash
grep -E '^[[:space:]]*events[[:space:]]*\{' nginx.txt
```

[Условия, команды и разбор задачи](../labs/intermediate/nginx-config.md)

### Как решить задачу «Статическая страница Nginx» на стенде?

Поднимите отдельный Nginx с loopback, явными путями и временным pid. Тело совпадает с index.html. При 403 проверьте права на проход по пути и пользователя worker.

Критерий приёмки проверяется в подготовленном стенде.

```bash
cmp www/index.html actual
```

[Условия, команды и разбор задачи](../labs/intermediate/nginx-static.md)

### Как решить задачу «Транзакция PostgreSQL» на стенде?

В транзакции создайте временную таблицу и вычислите сумму, затем откатите. Запрос выводит 5. При отказе проверьте параметры PGHOST и текущую роль, не меняя серверную аутентификацию.

Критерий приёмки проверяется в подготовленном стенде.

```bash
grep -Fx 5 pg.log
```

[Условия, команды и разбор задачи](../labs/intermediate/postgres-select.md)

### Как решить задачу «Проверка оглавления дампа» на стенде?

Создайте учебный dump custom и прочитайте TOC. В заголовке оглавления указан формат CUSTOM. Клиент pg_dump должен поддерживать версию сервера.

Критерий приёмки проверяется в подготовленном стенде.

```bash
grep -F 'Format: CUSTOM' toc
```

[Условия, команды и разбор задачи](../labs/intermediate/postgres-dump.md)

### Как решить задачу «Предпросмотр firewall» на стенде?

Постройте правило доступа к учебному SSH без применения. План показывает порт 2222. Используйте --dry-run перед подкомандой и проверьте реальный порт.

Критерий приёмки проверяется в подготовленном стенде.

```bash
grep -F 2222 plan
```

[Условия, команды и разбор задачи](../labs/intermediate/ufw-preview.md)

### Как решить задачу «Проверка файла nftables» на стенде?

Напишите независимую таблицу с цепочкой без hook и проверьте её без загрузки. Проверка завершается с кодом 0. Контейнер без CAP_NET_ADMIN не сможет проверить конфигурацию через ядро.

Критерий приёмки проверяется в подготовленном стенде.

```bash
sudo nft -c -f sample.nft
```

### Как решить задачу «Предпросмотр синхронизации» на стенде?

Определите, какой новый файл будет скопирован, не меняя назначение. План содержит note, файл ещё не скопирован. Завершающая косая черта выбирает содержимое source.

Критерий приёмки проверяется в подготовленном стенде.

```bash
grep -F note plan && test ! -e target/note
```

### Как решить задачу «Восстановление с хешем» на стенде?

Запишите хеш файла, восстановите из архива и проверьте внутри каталога назначения. Вывод note: OK. Манифест содержит относительный путь, запустите проверку из restore.

Критерий приёмки проверяется в подготовленном стенде.

```bash
(cd restore && sha256sum -c ../manifest)
```

### Как решить задачу «Поиск события в журнале» на стенде?

Создайте уникальную метку logger и получите сообщения текущей загрузки. В журнале видна строка health transition. При недоступной синхронизации подождите доставки события и проверьте права.

Критерий приёмки проверяется в подготовленном стенде.

```bash
journalctl --sync; journalctl -b -t "$tag" -o cat --no-pager | grep -Fx 'health transition'
```

### Как решить задачу «Интервалы vmstat» на стенде?

Соберите три отсчёта и сопоставьте r, b и wa. После двух строк заголовка три отсчёта. Уберите дополнительные флаги, если формат отличается.

Критерий приёмки проверяется в подготовленном стенде.

```bash
test "$(wc -l < samples)" -eq 5
```

[Условия, команды и разбор задачи](../labs/intermediate/resource-sample.md)

### Как решить задачу «Блоки и inode» на стенде?

Сопоставьте свободное место и число свободных inode для текущего каталога. Первый отчёт считает блоки, второй inode. На ФС без отчёта об inode поля могут содержать прочерки.

Критерий приёмки проверяется в подготовленном стенде.

```bash
LC_ALL=C df -Pi . | grep -F IUse%
```
