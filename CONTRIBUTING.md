# Вклад в справочник

Для исправления укажите главу и воспроизводимый пример. Для новой темы обозначьте аудиторию, версии системы и ожидаемый результат. Пишите учебный текст по-русски, а имена файлов, код, комментарии и сообщения коммитов по-английски.

1. Создайте рабочую ветку от актуального `main`.
2. Проверьте пример в одноразовой среде. Для изменений сети, дисков и служб укажите условия запуска и процедуру отката.
3. Запустите применимые проверки из каталога `tests` и опишите среду и фактические результаты в запросе на слияние.
4. Используйте Conventional Commits, например `docs: explain DNS resolver behavior`.

Перед публикацией примеров замените реальные учётные данные и адреса инфраструктуры учебными значениями. Указывайте первоисточники и лицензии заимствованного материала.
