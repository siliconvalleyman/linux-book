# Кодекс поведения

Обсуждайте технические решения уважительно, принимайте аргументированную обратную связь и помогайте участникам с разным опытом. Недопустимы персональные нападки, дискриминация, преследование и публикация чужих персональных данных без согласия.

Сообщить о нарушении можно сопровождающим через модерацию GitHub. Для открытой публикации выбирайте описание без персональных данных. Сопровождающие рассматривают контекст, ограничивают доступ к материалам жалобы и могут удалить сообщение или заблокировать участника. Повторное рассмотрение можно запросить через тот же канал.
