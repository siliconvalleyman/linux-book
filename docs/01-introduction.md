# 01. Введение в Linux

## Цели и предварительные требования

Определять семейство системы и различать версию дистрибутива и ядра.

Понадобится Bash и доступ к Linux.

## Как это работает

Дистрибутив поддерживает согласованный набор пакетов, ядро управляет ресурсами. Две системы с одинаковым ядром могут иметь разные менеджеры пакетов, библиотеки и сроки поддержки.

Официальные образы проверяют в два шага. Сначала подтверждают подпись списка контрольных сумм ключом проекта, полученным через отдельный доверенный канал. Затем сравнивают хеш конкретного файла ISO со списком. Проверка одного хеша из того же недоверенного источника не подтверждает происхождение.

## Синтаксис и практический пример

```bash
grep -E '^(ID|VERSION_ID)=' /etc/os-release
```

Флаг `-E` включает расширенное регулярное выражение. Поле `ID` обозначает текущий дистрибутив, а `VERSION_ID` может отсутствовать у системы с непрерывными обновлениями. В Debian ожидается строка `ID=debian`.

### Введение в Linux

Linux — свободное ядро операционной системы с открытым исходным кодом, созданное Линусом Торвальдсом в 1991 году.

Операционные системы на базе Linux широко используются в серверной инфраструктуре, разработке программного обеспечения, облачных вычислениях и информационной безопасности.

#### Где используется Linux?

- Веб-серверы
- Суперкомпьютеры
- Облачные платформы
- Центры обработки данных
- DevOps-инфраструктура
- Информационная безопасность
- Искусственный интеллект
- Встраиваемые системы
- Мобильные устройства
- Персональные компьютеры
- Сетевое оборудование
- Контейнеризация

#### Преимущества Linux

- Открытый исходный код
- Гибкость настройки
- Стабильность
- Высокая производительность
- Развитая система безопасности
- Возможность автоматизации
- Большое сообщество разработчиков
- Поддержка различных архитектур процессоров

### Дистрибутивы Linux

Дистрибутив — готовая операционная система, включающая ядро Linux, системные утилиты, пакетный менеджер и дополнительное программное обеспечение.

#### Рекомендации

- Для начинающих — Ubuntu или Linux Mint.
- Для разработчиков — Ubuntu или Fedora.
- Для серверов — Debian, Ubuntu Server или Rocky Linux.
- Для DevOps — Ubuntu Server, Debian или Alpine Linux.
- Для специалистов по безопасности — Kali Linux.
- Для глубокого изучения Linux — Arch Linux или Gentoo.

## Применение и диагностика

В контейнере версия дистрибутива может отличаться от хоста при общем ядре.

При выборе инструкции сравните ID и ID_LIKE. Если uname показывает необычный суффикс, проверьте, запущена ли система в ВМ, WSL или контейнере.
