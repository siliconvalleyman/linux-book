# 05. Терминал и оболочка

## Цели и предварительные требования

Предсказывать разбиение аргументов и перенаправление потока.

Понадобится Интерактивный Bash.

## Как это работает

Терминал передаёт ввод процессу оболочки. Bash выполняет подстановки, строит массив аргументов и соединяет файловые дескрипторы до запуска команды. В двойных кавычках работают подстановки переменных, но отключены разбиение по полям и раскрытие glob.

Код завершения можно прочитать из $? только до исполнения следующей команды. Для сохранения всех статусов конвейера в Bash считайте PIPESTATUS сразу. При перенаправлении Bash обрабатывает операции слева направо, поэтому порядок записи stderr следует проверять отдельно.

## Синтаксис и практический пример

```bash
name='two words'; printf '<%s>\n' "$name"
```

Формат %s печатает один строковый аргумент, кавычки сохраняют пробел.

Ожидаемый результат для примера. Появляется единственная строка `<two words>`.

## Справочные примеры

> Команды ниже предназначены для учебной среды. Операции с `sudo`, разделами, сетью, системными службами и учётными записями выполняйте только в одноразовой ВМ с доступом к её консоли.

### Терминал и командная строка

Терминал позволяет взаимодействовать с операционной системой через текстовые команды.

#### Популярные командные оболочки

- Bash
- Zsh
- Fish
- Dash
- Ksh

Проверка оболочки пользователя:

```bash
echo "$SHELL"
```

Общий синтаксис команды:

```text
command [options] [arguments]
```

Пример:

```bash
ls -la /home
```

#### Основные команды

| Команда | Описание |
|---|---|
| `pwd` | Текущий каталог |
| `ls` | Список файлов |
| `cd` | Переход между каталогами |
| `clear` | Очистка терминала |
| `whoami` | Текущий пользователь |
| `hostname` | Имя компьютера |
| `date` | Дата и время |
| `cal` | Календарь |
| `history` | История команд |
| `uname` | Информация о ядре |
| `man` | Документация команды |
| `which` | Поиск исполняемого файла |
| `type` | Определение типа команды |
| `exit` | Завершение сеанса |

Получение справки:

```bash
man ls
ls --help
help cd
```

Некоторые команды требуют установки дополнительных пакетов.

### Переменные окружения

#### Просмотр переменных

```bash
env
printenv
echo "$PATH"
echo "$HOME"
echo "$USER"
```

#### Создание переменной

```bash
export APP_ENV=production
```

#### Удаление переменной

```bash
unset APP_ENV
```

#### Основные переменные

| Переменная | Назначение |
|---|---|
| PATH | Пути поиска команд |
| HOME | Домашний каталог |
| USER | Имя пользователя |
| SHELL | Командная оболочка |
| LANG | Языковые настройки |
| PWD | Текущий каталог |
| TERM | Тип терминала |
| EDITOR | Предпочитаемый редактор |

#### Постоянные настройки

```text
~/.bashrc
~/.profile
~/.zshrc
/etc/environment
```

Добавление каталога в PATH:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

Применение настроек Bash:

```bash
source ~/.bashrc
```

Не храните секретные ключи и пароли в публичных репозиториях.

### Перенаправление и конвейеры

#### Стандартные потоки

| Поток | Дескриптор |
|---|---|
| stdin | 0 |
| stdout | 1 |
| stderr | 2 |

#### Перенаправление вывода

```bash
echo "Hello" > file.txt
echo "Linux" >> file.txt
```

#### Перенаправление ошибок

```bash
command 2> errors.log
```

#### Объединение потоков

```bash
command > output.log 2>&1
```

#### Конвейеры

```bash
ls -la | less
pgrep -a nginx
cat file.txt | sort | uniq
```

#### Обработка текста

```bash
sort file.txt
uniq file.txt
cut -d ':' -f 1 /etc/passwd
```

#### AWK

```bash
awk -F ':' '{print $1}' /etc/passwd
```

#### SED

```bash
sed 's/old/new/g' file.txt
```

#### Tee

```bash
echo "Hello Linux" | tee output.txt
```

#### Xargs

```bash
find . -name "*.txt" -print0 | xargs -0 -r wc -l
```

#### Проверка JSON

При установленном `jq`:

```bash
curl -s https://api.example.com/data | jq .
```

## Применение и диагностика

При ошибке с путём с пробелами выведите аргументы через printf '%q\n' и проверьте кавычки.

Не вставляйте неизвестный текст в терминал. Команды и значения переменных могут попасть в историю и трассировку Bash.

## Практика и самопроверка

1. Сравните варианты с кавычками и без них. Сделайте это с переменной без символов glob.
2. Почему порядок 2>&1 и > файл влияет на итог?
