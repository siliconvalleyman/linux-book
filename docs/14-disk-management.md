# 14. Диски и монтирование

## Цели и предварительные требования

Объяснять работу компонентов темы «Диски и монтирование» и проверять их состояние на практике.

Понадобится Учебная ВМ Linux и [предыдущая глава](13-ssh.md).

## Как это работает

Флаг -o выбирает поля. Устройство, раздел, файловая система и точка монтирования относятся к разным слоям; UUID ФС устойчивее имени /dev/sdX.

Тип файловой системы определяет допустимые операции изменения размера. XFS можно увеличивать в смонтированном состоянии, уменьшение зависит от поддержки ФС и версии инструментов. До изменений раздела снимите копию данных и сверяйте путь по UUID, размеру и серийному номеру. Для чтения используйте lsblk и findmnt.

## Синтаксис и практический пример

```bash
lsblk -o NAME,TYPE,FSTYPE,UUID,MOUNTPOINTS
```

Ожидаемый результат для примера. Для разделов с ФС появляются тип и UUID, для дисков без ФС поля пусты.

## Справочные примеры

> Команды ниже предназначены для учебной среды. Операции с `sudo`, разделами, сетью, системными службами и учётными записями выполняйте только в одноразовой ВМ с доступом к её консоли.

### Работа с дисками

> **Внимание.** Изменения из этого раздела выполняйте только в одноразовой ВМ со снимком.

#### Просмотр дисков

```bash
lsblk
lsblk -f
sudo fdisk -l
df -h
sudo blkid
```

#### Использование дискового пространства

```bash
du -sh /home
du -h --max-depth=1 /var
df -Th
df -i
```

#### Монтирование

```bash
sudo mkdir -p /mnt/data
sudo mount /dev/disk/by-id/LAB_PARTITION /mnt/data
```

Размонтирование:

```bash
sudo umount /mnt/data
```

#### Постоянное монтирование

Файл:

```text
/etc/fstab
```

Пример записи:

```text
UUID=YOUR-DISK-UUID /mnt/data ext4 defaults,nofail 0 2
```

UUID можно получить командой:

```bash
sudo blkid
```

Проверка конфигурации:

```bash
sudo findmnt --verify
```

#### Форматирование

```bash
# Run only against the designated disposable VM disk.
sudo mkfs.ext4 /dev/disk/by-id/LAB_DISK
```

> Внимание: форматирование уничтожает данные на выбранном разделе. `LAB_DISK` приведён только в качестве примера. Перед выполнением необходимо точно определить нужное устройство и размонтировать его.

#### Дополнительные технологии

- LVM
- RAID
- Swap
- Disk Encryption
- LUKS
- Btrfs Snapshots

## Применение и диагностика

При ошибке загрузки проверьте fstab через findmnt --verify и сопоставьте UUID с lsblk. Форматируйте только выделенный диск учебной ВМ.
