# 08. Права доступа

## Цели и предварительные требования

Объяснять режимы, ACL и маску создания.

Понадобится Временный каталог с поддержкой POSIX-прав.

## Как это работает

Для каталога x разрешает обход, r даёт чтение списка имён, w разрешает менять записи при наличии обхода. ACL добавляет именованных пользователей и группы. ACL mask ограничивает эффективные права группы-владельца и дополнительных записей.

Биты SUID и SGID на исполняемом файле могут менять эффективные идентификаторы после exec. Для каталога SGID задаёт наследование группы. Sticky bit в общем каталоге ограничивает удаление чужих записей. На ФС с default ACL режим нового объекта определяется наследуемыми разрешениями и режимом, запрошенным при создании.

## Синтаксис и практический пример

```bash
file=$(mktemp); chmod 640 "$file"; stat -c '%a' "$file"; rm -- "$file"
```

chmod задаёт восьмеричный режим. GNU stat -c выбирает представление режима, rm -- завершает список опций.

Ожидаемый результат для примера. Команда stat выводит 640.

## Справочные примеры

> Команды ниже предназначены для учебной среды. Операции с `sudo`, разделами, сетью, системными службами и учётными записями выполняйте только в одноразовой ВМ с доступом к её консоли.

### Права доступа

Linux использует три основные категории доступа:

- Owner — владелец.
- Group — группа.
- Others — остальные пользователи.

#### Типы разрешений

| Символ | Значение | Число |
|---|---|---|
| `r` | Чтение | 4 |
| `w` | Запись | 2 |
| `x` | Выполнение | 1 |
| `-` | Нет разрешения | 0 |

Пример:

```text
-rwxr-xr--
```

```text
Owner:  rwx = 7
Group:  r-x = 5
Others: r-- = 4
```

#### chmod

```bash
chmod 755 script.sh
chmod 644 file.txt
chmod 600 private.key
chmod 700 private-directory
```

Символьный режим:

```bash
chmod u+x script.sh
chmod g+w file.txt
chmod o-r file.txt
```

#### chown

```bash
sudo chown developer file.txt
sudo chown developer:developers file.txt
```

#### chgrp

```bash
sudo chgrp developers file.txt
```

#### Популярные комбинации

| Права | Назначение |
|---|---|
| 600 | Приватные файлы и ключи |
| 644 | Обычные файлы |
| 640 | Файлы с ограниченным доступом |
| 700 | Приватные каталоги и скрипты |
| 755 | Исполняемые файлы и каталоги |
| 750 | Каталоги с ограниченным доступом |
| 777 | Полный доступ для всех, для учебных примеров используйте более узкий режим |

#### Специальные разрешения

- SUID
- SGID
- Sticky Bit

```bash
chmod g+s shared-directory
chmod +t shared-directory
```

#### ACL

Расширенное управление правами:

```bash
getfacl file.txt
setfacl -m u:developer:rw file.txt
setfacl -x u:developer file.txt
```

#### umask

```bash
umask
umask 027
```

`umask` определяет, какие разрешения исключаются при создании новых файлов и каталогов.

## Применение и диагностика

Если файл доступен по режиму, но open возвращает EACCES, проверьте родительские каталоги через namei -l и ACL через getfacl.

Назначайте минимально необходимые права. Проверяйте совместное действие ACL и специальных битов перед развёртыванием.
