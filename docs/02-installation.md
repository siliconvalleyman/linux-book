# 02. Установка Linux

## Цели и предварительные требования

Выбрать среду и проверить способ запуска.

Понадобится Доступ к гипервизору или WSL.

## Как это работает

Образ ВМ предоставляет собственное ядро и устройства, WSL имеет отдельную модель интеграции с Windows, контейнер зависит от ядра хоста. Для упражнений о загрузке и дисках нужна полноценная ВМ.

На ноутбуке с Dual Boot до изменения разделов проверьте шифрование, режим загрузки UEFI и наличие ключа восстановления Windows. Для базового стенда выделите гостевой системе отдельный виртуальный диск и подключите ISO только на время установки. Снимок сделайте после первого входа и установки системных обновлений.

## Синтаксис и практический пример

```bash
ps -p 1 -o comm=
```

Параметр -p выбирает PID, -o задаёт поле, завершающий знак равенства скрывает заголовок.

Ожидаемый результат для примера. В типовой ВМ Ubuntu выводится systemd. В контейнере PID 1 может быть оболочкой или приложением.

## Справочные примеры

> Команды ниже предназначены для учебной среды. Операции с `sudo`, разделами, сетью, системными службами и учётными записями выполняйте только в одноразовой ВМ с доступом к её консоли.

### Установка Linux

#### Способы установки

1. Установка на физический компьютер.
2. Установка рядом с Windows (Dual Boot).
3. Использование виртуальной машины.
4. Использование Windows Subsystem for Linux (WSL).
5. Использование облачного VPS-сервера.
6. Запуск с Live USB.

Перед установкой на физический диск необходимо создать резервную копию важных данных.

#### Установка через WSL

Откройте PowerShell от имени администратора:

```powershell
wsl --install
```

Просмотр доступных дистрибутивов:

```powershell
wsl --list --online
```

Установка Ubuntu:

```powershell
wsl --install -d Ubuntu
```

Просмотр установленных систем:

```powershell
wsl --list --verbose
```

Обновление WSL:

```powershell
wsl --update
```

#### Первоначальная настройка Ubuntu

```bash
sudo apt update
sudo apt upgrade
```

Установка основных инструментов:

```bash
sudo apt install curl wget git vim nano htop tree \
    build-essential unzip openssh-client
```

Проверка версии системы:

```bash
cat /etc/os-release
```

## Применение и диагностика

Если systemctl не подключается к менеджеру, проверьте PID 1 перед настройкой служб. Для практики с UEFI загрузите ВМ из официального ISO.

Перед установкой на реальный диск создайте проверяемую резервную копию. ВМ начинайте со снимка и отдельного виртуального диска.
